# LOVE HAND — Python Web Version

Python tetap digunakan untuk Flask + OpenCV + MediaPipe. Browser hanya menangani webcam dan tampilan partikel.

## Lokal
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```
Buka http://127.0.0.1:5000

## GitHub
Upload seluruh isi folder ini ke repository GitHub. GitHub Pages tidak menjalankan app.py.

## Hosting
Gunakan hosting yang mendukung Python/Docker. Dockerfile sudah disediakan. Setelah online dengan HTTPS, buka URL hosting lalu izinkan kamera.
